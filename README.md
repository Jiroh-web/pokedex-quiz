# ポケモン図鑑クイズ

React と [PokeAPI](https://pokeapi.co/) を使って作った、ポケモンの名前を当てるクイズ＆図鑑アプリです。図鑑番号順に挑戦する「地方モード」や、ランダムに10問出題される「ランダムモード」でクイズに挑戦できるほか、地方ごとの図鑑を眺めて発音を確認することもできます。

## デモ

🔗 https://jiroh-web.github.io/pokedex-quiz/

## 特徴

### クイズ機能
- 🗾 **地方モード**：カントーからガラルまで、地方ごとに図鑑番号順で出題
- 🎲 **ランダム10問モード**：全国図鑑からランダムに10匹出題、正解数を集計
- 🇯🇵 **日本語名で出題**：PokeAPIの多言語データから日本語名を取得して表示

### 図鑑機能
- 📖 **地方別図鑑**：地方ごとに範囲を絞ってポケモン一覧を閲覧
- 🌐 **日本語/英語 切り替え**：ワンタップで表示言語を切り替え
- 🔊 **発音ボタン**：英語表示時、ブラウザの音声合成機能でネイティブに近い発音を再生

### ユーザー管理・記録
- 👤 **ユーザー管理**：名前を登録するだけで、個人ごとの解答履歴を記録(ブラウザ内保存)
- 📊 **記録・正答率の確認**：これまでの正答率や、間違えたことのあるポケモン一覧を確認可能

## 使用技術

- [React](https://react.dev/)（[Vite](https://vitejs.dev/) でセットアップ）
- [PokeAPI](https://pokeapi.co/)（ポケモンデータ取得）
- Web Speech API（`SpeechSynthesis`、英語発音の読み上げ）
- localStorage（ユーザー情報・解答履歴の保存、ブラウザ内のみ）
- GitHub Pages（`gh-pages` によるホスティング）

## セットアップ方法

```bash
git clone https://github.com/Jiroh-web/pokedex-quiz.git
cd pokedex-quiz
npm install
npm run dev
```

`http://localhost:5173` にアクセスすると起動します。

## 公開サイトの更新方法

```bash
npm run build
npm run deploy
```
